# Agent 手册

写给 Agent 看的说明书：Agent 用户型结构 Skill 读图、写方案、试改造、出图交付，或者和改改你的家（本 app）配合时，需要知道的事实和做法。

本仓库包含第 1–8 篇及「相机与素材通道」附篇；装修篇目前仍为占位。配套 Skill 见 https://github.com/ai-azhou/see-your-home 。

**事实以代码为准**：字段、单位、缺省值、改造规则、命令行为都来自 `src/core/`（`types.ts`、`io.ts`、`validate.ts`、`changes.ts`、`mesh.ts`、`raster.ts`、`handoff.ts`）、`schema/plan.schema.json`、`scripts/plan.ts`、`scripts/serve.mjs`。改了这些代码的行为，同一次提交里改对应的篇目。

| 篇 | 文件 | 什么时候读 | 进 Skill |
| --- | --- | --- | --- |
| 1 格式 | [格式.md](格式.md) | 写或改方案 JSON；字段、单位、缺省值、evidence 规则 | 是 |
| 2 读图 | [读图.md](读图.md) | 定比例、读结构、看不懂的画法、面积对照、问题卡 | 是 |
| 3 改造 | [改造.md](改造.md) | 拆、改、加；pending 和 confirmed；二次确认；改完重出 | 是 |
| 4 工具连接 | [工具连接.md](工具连接.md) | 用户从工具粘来交接文字；服务模式下改文件；用户贴来给网页 Chat 用的内容 | 是（v1.1 起） |
| 5 命令 | [命令.md](命令.md) | 路径、环境检测、每条命令、错误码、辅助脚本、耗时 | 是 |
| 5 附 | [相机与素材通道.md](相机与素材通道.md) | 房间平视机位、自定义相机、深度线稿分割遮罩 | 是 |
| 6 交付 | [交付.md](交付.md) | 第 0 步路线图、交付前检查、说明怎么写、口径禁语、附录、每次交付末尾的「下一步」和工具串联 | 是 |
| 7 装修 | [装修.md](装修.md) | 占位，装修阶段定稿后补 | 否 |
| 8 生图 | [生图.md](生图.md) | 用户想看「装好大概什么感觉」：挑模型、出素材、提示词、打分重试、交付口径 | 是 |

写这些篇目的规矩：准确、可执行、有例子；只讲客观事实，不替用户做专业判断；不夹带某个城市、开发商、品牌的知识清单。进 Skill 的篇目之间可以互相链接，不要链接到不进 Skill 的篇目（装修）和 app 里的其他文件。
