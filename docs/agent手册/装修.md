# 7 装修（占位）

**什么时候读**：交接文字的模式是「装修」，或用户要摆家具、做柜子、换墙面地面材料时。

**装修阶段定稿后补。** 现在不要据此写装修数据；装修层 `decor` 的现有契约见 `docs/format.md` 的「装修层」各节，只作开发参考。

定稿后这篇要讲清：

- 装修层 `decor` 和结构的关系：直接存当前状态，不写进结构 `changes`；只挂在已确认改造后的结构上。
- 装修项的 `by` / `status`：Agent 新增或修改的标 `pending`，用户确认后改 `confirmed`。
- 单位：文件里装修的长度和高度全是 mm；墙面定位 `FaceRef={wall,side}`、沿墙 `s`、离地 `z` 怎么量。
- 家具、柜体、造型、壁龛、墙地顶材料各写什么字段，必填和缺省。
- 挂靠和重挂：拆墙、改墙以后装修项怎么跟着走，「没地方挂」怎么处理。
- 碰到承重墙、外墙、承重柱、管井的嵌入：只给事实提示，不替用户判断能不能做。
- 校验命令和问题码（`decor` 命令、`decor-*` 问题）。
- 交接文字里 `## 装修构件（ref）` 那一段的结构。
- 交付：装修效果图、材料粗估怎么说，口径和禁语。
