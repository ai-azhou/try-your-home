# 装修阶段功能设计（E1）

> 10-29 E1。给 PM 和下一轮实现者。界面规格见 `设计规范.md`，数据见 `数据格式草案.md`，样张在 `样张/png/`。

## 0. 一句话

**还是那块白模工作台，顶部多一段「装修」：把材料铺在改造后的白模上，平面看全屋、立面做墙面；结构的颜色继续只说「要你注意」，材料的颜色退一档，只说「这里铺了什么」。**

第一期只做 2D（平面 + 立面），3D 不做建模，只在探针里试白盒（见 `探针计划.md`、`待本人讨论.md`）。

## 1. 范围和分期

| | 做什么 | 为什么在这一期 |
|---|---|---|
| **第一期（2D 核心）** | 装修态入口和画布；6 套风格预设；地面、墙面换材质（整面 / 一段 / 到某个高度）；家具库约 40 件；柜子（高柜、地柜、吊柜，分列分格，挖洞，台面，嵌进墙）；墙面立面编辑器；造型（背景墙板、护墙板、格栅、踢脚线、拱形门套）；挖（墙上 = 壁龛 / 嵌入，造型和柜子上 = 挖洞）；结构联动（没地方挂、重新挂接、受保护墙的事实说明）；改造清单导出加「装修想法」；交给 Agent 能带装修构件 | 业主最先想试的就是这些：铺什么地、刷什么墙、家具放不放得下、电视墙和柜子长什么样。全部能在平面 + 立面里说清楚，不需要建模 |
| **第一期 b（2D 补充，看排期）** | 吊顶（只做平吊下沉、边吊：立面上看得到顶线降下来一圈，平面上画虚线范围）；窗帘（平面波浪线 + 立面）；地面铺法细调（人字拼、鱼骨拼、斜铺的起铺点）；收边材料；灯位符号（只占位，不算光） | 常用，但不影响主路径；吊顶和梁关系大（包梁），需要先看探针里梁和造型的交接 |
| **留给 3D 讨论** | 装修在 3D 里怎么呈现（白盒 / 程序建模 / 模型库 / 生图）；柜体内部（挂衣杆、裤架、拉篮）；造型吊顶；贴弧墙的造型；灯光和氛围；写实效果图；漫游 | 本人 10-29：「3D 本人要再和我们专门讨论」。几种方向的代价见 `待本人讨论.md` |
| **这一阶段不做** | 报价、预算；品牌商品库；施工图（水电点位、节点大样）；联网查家电尺寸 | 工具给业主试想法、和专业人士沟通，不替专业人士出图出价 |

## 2. 用户的主要路径

从「结构确认完」到「看到装修后的家」。每一步屏幕上只有一个该看的地方：

| 步 | 用户在干什么 | 屏幕上 | 下一步条（底部，一句话 + 一个按钮） |
|---|---|---|---|
| 0 | 结构差不多了 | 对比态看完拆了什么加了什么 | 现有规则 6 后面加一条：改造模式没有待确认的提议时，「结构定了」+「开始装修 →」 |
| 1 | 第一次进装修 | 顶部第四段「装修」亮起；平面还是白模；右侧直接是**风格卡**（样张 02） | 「先选一个整体风格，之后每块地、每面墙都能单独改」 |
| 2 | 挑风格 | 悬停一张风格卡，平面实时换成那套材料；点一下应用，材料一间一间铺进去（错峰 60ms，和热点冒出来同一个节奏） | 「正在预览，Esc 回到…」 |
| 3 | 看全屋 | 右侧换成**这套房的装修**（样张 01）：风格、要你看一下的事、用到的材料 | 「从家具库拖几件进来，看看放不放得下」+「打开家具库」 |
| 4 | 放家具、换材质 | 左侧工具：家具、材质；点地面 = 选地面，点墙边 = 选那一侧的墙面（样张 05） | 选中时只给一句怎么改，不给按钮（和现有规则 1 一样） |
| 5 | 做一面墙 | 双击墙面（平面或 3D 都行），或选中后「进立面做造型」→ 主画布换成这面墙的立面，画中画换成平面并标出看的是哪面墙（样张 03）。D6：立面按房间分段——双击在哪间房里就进这间房那一段，‹ › 绕这间房走，墙连着别的房间时标题旁「这面墙还连着 书房 ›」 | 「拖四边改尺寸，拖进墙里就是嵌入」 |
| 6 | 做柜子 | 平面上沿墙拖出柜子，双击进**柜体编辑**（立面放大到这个柜子，样张 04） | 「点格子换类型，拖竖线改列宽」 |
| 7 | 拿去沟通 | 右上角全局「导出」（D6，任何模式都能点）：改造清单 PDF（「结构改造」「装修想法」两节分别勾）、方案 JSON、当前 3D 视角的平涂 / 白模图。PDF 是结构改造 + 装修想法，一个 PDF（D5 已做：装修总览 → 每个房间一块（平面局部 + 装修最多那面墙的立面）→ 用到的材料 + 家具尺寸 → 需要专业确认） | 有内容时：「已选风格 · 28 项装修」+「改造清单导出」 |

随时：结构改动让装修挂不住了，下一步条优先显示柠檬色「拆掉次卧南墙后，1 项装修没地方挂了」+「去处理」（样张 01）。

**第一眼知道操作哪里**：左边 5 个工具（选择、材质、家具、柜子、立面），右边一张卡，底下一句话。没有新增浮层，没有工具条套工具条。

## 3. 装修态和「原始 / 改造 / 对比」怎么共存

- **装修是顶部分段的第四段**，排在对比后面，中间一道细分隔线，读起来就是流程：原始 → 改造 → 对比 ‖ 装修。快捷键 `4`。不另做「阶段开关」：一个开关只能多一个心智负担，而分段本来就是「我现在在看哪个版本的家」。
- **装修态画的是改造后的结构**：已确认的改造全部生效；Agent 待确认的结构提议照旧画淡紫斜纹，不当真。
- **装修态里结构只读**：点墙选中的是墙面（哪一侧），不是墙本身；检查器底部有「去改造里改这面墙」，按 `2` 切过去。理由：一次只改一层，撤销才不乱；业主也不会「刷墙的时候顺手把墙拆了」。
- **原始 / 改造 / 对比默认不画装修**。图层菜单加一项「装修（淡显）」：打开后家具和柜子只画淡墨轮廓，改造时看得到「这面墙上挂着东西」。
- **改造态里动到挂着装修的墙**：检查器和删除确认卡里多一行事实（「这面墙上有 2 项装修：电视背景墙、嵌墙柜。拆了以后它们会没地方挂，到装修里再处理」），不拦。
- **对比态只比结构**。装修没有「原来」，不进对比。
- **撤销历史**：原始、改造、装修各一条；换风格算一步。
- **背景**：装修态的柔光换一套（左下薄荷换成很淡的杏色），不用横幅也知道在哪一章（设计规范 §1）。

## 4. 每个功能的交互

### 4.1 选风格（样张 02）

- 风格卡（右侧卡）：6 张风格卡两列排，每张是一块**材料板**（地面、墙漆、木、石、布、金属的真实色块摆成一组）+ 名字 + 三个关键词。不放效果图：效果图会让人以为「装出来就是这样」，而且我们画不出来。
- 悬停 = 平面实时预览，Esc 还原；**点一下 = 选中并继续预览，按「应用」（或双击、↵）才生效**（本人 10-29 定，和样张 02 一致）。底部开关「保留我单独改过的 N 处」默认开，列出是哪几处；关掉再应用 = 单独换过的墙面、地面回到新风格默认，造型换成新风格的点缀墙材料。
- **应用算一步撤销**：⌘Z 整步撤回到应用前（风格、被「不保留」清掉的那几处覆盖、造型材料一起回来）；悬停预览、点选都不进撤销。
- 最后一张是淡紫的「说一句想要的感觉，让 Agent 配一套」：Agent 写一个自定义风格（`pending`），出现在列表里，带淡紫角标，用户应用了才算确认。
- 内置 6 套：奶油原木、侘寂、现代极简、中古、北欧、新中式。风格名只是材料组合的名字，不是设计建议。

### 4.2 材质：地面、墙面（样张 01、05）

- **点哪选哪**（装修态的选择工具）：点房间中间 = 这间房的地面；点墙边（墙面往房间里 300mm 以内）= **靠近这一侧的墙面**，只亮这一面（薄荷色带贴着墙面画，另一面不亮）；点家具、柜子 = 选中它。
- **墙有两侧**（D6）：平面上悬停 / 选中墙面时，色带旁一个小标签「客厅一侧 / 室外一侧」；3D 里同样。外墙点在墙体上默认选室内一侧，明确点在墙外才选室外一侧。立面标题第三行写「从客厅看 · 面朝西看」。
- **墙面检查器**：小立面（这面墙长什么样，靠墙的家具淡显帮你认墙；墙跨两间房时只画这间房那一段）→ 当前材料（「单独改过 · 风格默认是奶油白」+「回到默认」）→ 材料分类和色块 → 刷到哪（整面 / 选一段 / 到某个高度）→ 另一面是什么（「切过去」）→ 吸底「进立面做造型」。
- **材质工具**（刷子）：顶部提示条下有当前材料胶囊，点它换；点地面、墙面直接刷；按住 ⌥ 点 = 吸取。
- 面积自动扣掉门窗洞口，标「约」：粗估，只用来对量级。
- 不同地面材料相接的门洞自动铺「门槛石」（风格的 `threshold` 角色，可关）；拆墙留下的墙位，地面按两侧接上，不留缝。

### 4.3 放家具

- **家具库**（右侧卡）：分类胶囊（客厅、卧室、餐厨、书房、卫浴、家电、收纳、软装）+ 搜索；每格画的是和画布上**同一个平面符号**（不是图标）+ 名字 + 尺寸「2400 × 900」，下面一行小字「常见尺寸，放下后可改」。
- 拖进平面，或点一下再在平面上点。离墙面 150mm 以内背面自动贴墙（记下 `against`）。`R` 转 90°，拖转柄自由转（15° 吸附）。拖四边改尺寸。
- **拖的时候显示四个方向的净距**（复用测距的洋红胶囊，测距 spec 第二期）：到墙面、到别的家具，例如「过道 780」。只给数，不判断够不够。图层里可以打开「常见尺寸参考」（默认关），标「常见值」。
- 挡门：拖到门扇扫过的范围里时，那扇门的开启弧变柠檬虚线，写「挡门」。只提示，放下照放。
- 叠放（床尾凳压着床、地毯在沙发下面）允许，地毯永远在最下面。

### 4.4 柜子

- **平面上画**：柜子工具，顶部类型胶囊「高柜 · 地柜 · 吊柜」，常见深度作默认（高柜 600、书柜 400、地柜 600、吊柜 350，标常见值）。悬停墙面出薄荷预览，沿墙拖出宽度（吸附墙角、洞口边、别的柜子）。在空地拖 = 独立柜（岛台）。
- 新柜子按宽度自动分列（每列不超过 900，常见值），默认全是门。
- **柜体编辑**（双击柜子，或检查器「编辑分格」；样张 04）：主画布是这面墙的立面放大到这个柜子，其他东西不动；
  - 点一格 → 检查器换这一格的类型：单开门、对开门、抽屉、开放格、**挖洞**、家电位；
  - 拖立面上的竖线改列宽，顶部的薄荷小柄就是抓手；右边「+」加一列；
  - 挖洞：「挖穿柜体（露出墙面）/ 留背板」；洞里可以加一块台面（书桌、梳妆台）：高度、出柜多少；
  - 家电位：选冰箱、洗衣机、烘干机、烤箱、蒸箱、洗碗机、电视，用常见尺寸画虚线外形，可改；
  - 跨格的洞：用「挖」工具在柜子上框一块，压到的格子自动裁掉。
- **平面画法跟着分格走**：剖切 1.1m 处是柜体的画交叉线，是挖洞的画虚线（上面还有柜子）+ 细实线（下面的台面）。业主不用懂规则，但平面上看得出「这里是空的」。
- 嵌进墙：检查器「嵌进墙里」步进器；或在平面上把柜子往墙里拖，过了墙面有一下阻尼（停在 0），继续拖就嵌进去。规则同 4.6。

### 4.5 造型（在立面里做；样张 03）

第一期做五种，都是「贴在墙面上、不分隔空间」的：

| 造型 | 参数 | 立面上 | 平面上 |
|---|---|---|---|
| 背景墙板 | 范围、出墙厚度（常见 20–200，含龙骨）、材料、分缝（竖 / 横 / 无） | 材料平涂 + 分缝细线，右侧一道软影（凸出来） | 墙面前一条实际厚度的色条 |
| 护墙板 | 到某个高度、框线样式（平板 / 线框）、顶线 | 同上 + 框线 | 同上 |
| 格栅 | 条宽、间隙、条深 | 竖条 | 一排细格 |
| 踢脚线 | 跟风格，某面墙可换色、取消 | 底边一条 | 不画（太细） |
| 拱形门套 | 套在哪个门洞、拱顶半径（缺省半圆） | 门洞上半部填成拱形 | 不变 |

- 拱形门套是「在原门洞里用石膏板做出拱形」，不改洞口；要把洞口真的改成拱形，是结构改造（待讨论）。自立的弧形隔断去改造里加墙（10-29 本人定的归类）。
- **吸附**：墙面两端、门窗的洞底洞顶、梁底、顶面、其他造型的边、这面墙的中线。吸到了旁边出墨色胶囊「对齐 梁底 2.55」，和画墙工具的吸附提示同一个样子。
- 造型盖到门窗时自动让开（造型板上扣掉洞口），立面上看得到让开的形状。

### 4.6 嵌墙：家电、柜体嵌进墙体

- 两种做法：柜子 / 家电「嵌进墙里 N mm」；或者用「挖」工具在墙上框一块 = 壁龛（可以空着、加层板、换背板材料）。
- **不挖透**：深度必须小于墙厚；两侧都挖时两边加起来小于墙厚；碰到门窗洞口、管道井不行；玻璃墙不行；矮墙只能挖在实体部分。输入挖到墙厚的值时**不写数据**（保留上一次的有效值，不替用户改成别的数），输入框下面就地提示「挖到 240 就穿了，那是开洞，属于结构改造」+「去改造开洞」（转到改造态、选中这面墙、开门洞工具）。
- 检查器里有**俯视局部图**（样张 03 右侧）：外墙墨灰、柜子交叉线、原墙面虚线，标「墙厚 240 · 挖进 120 · 剩 120 · 柜深 420」，横竖同一比例尺。这是讲清「挖一部分但不挖透」最直接的地方。
- **受保护的墙**（承重墙、外墙，按改造后和原始类型取严）：检查器第二行是一张墨色锁的事实卡（样张 03）：

  > **这面在方案里是外墙（读图看到）**
  > 在外墙上挖槽、嵌入能不能做、能挖多深，要专业人员到现场确认。这里只画效果，会记进改造清单的「需要专业确认」。
  > [知道了] 不影响继续画

  - 只陈述两件事实：方案里它是什么墙（附把握程度），以及「要专业人员确认」。不说「危险」「不建议」「不可以」。
  - 不拦：照画、照存；点「知道了」记 `ack`，卡片收起成一行，锁的标记一直在。
  - 墙的类型是推断的，文案改成「读图推断是承重墙，没确认」，并给「去核对这面墙」（打开那条问题卡）。

### 4.7 挖洞：柜子上、石膏板上

- 同一个「挖」工具，**挖在哪由你框在哪决定**：框在造型板、柜子上 = 在它上面挖洞；框在空墙上 = 壁龛（4.6 的规则）。检查器标题写清「挖在：电视背景墙（造型，厚 150）」。
- 挖在造型 / 柜子上可以选「挖穿（露出后面的墙面）」或「留 N mm」；不能深过宿主。要再往里，就是挖进墙了，按墙的规则重新判断（受保护墙照样出事实卡）。
- 电视位的例子（样张 03）：背景墙板出墙 150，电视位挖进 100，不碰墙体；电视作为家电放进洞里（`in`）。
- 洞的边可以加收边（1b）。

### 4.8 交给 Agent

- 装修构件也能选中交给 Agent；交接文字用白话写墙面（「客餐厅西墙（外墙）朝房间那一面，从左数 120–720 mm，离地 0–2.40 m」），附 id。
- Agent 写回的装修构件是 `pending`，画淡紫斜纹，检查器第二行「我确认 / 撤销这条」，和结构提议一样。
- 常见用法：「按我的描述配一套风格」「这面墙做个书柜，中间留书桌」「把电视墙做成微水泥，电视嵌进去」。

## 5. 和结构层的关系

### 5.1 结构改了，挂在那面墙上的造型怎么办

规则写在 `数据格式草案.md §9`，交互上：

- **数据不动，画面先说**：挂不住的构件画在原处，柠檬斜纹 + 柠檬虚线 + 柠檬热点（样张 01 书房里那块）；「这套房的装修」卡里「要你看一下」第一条；下一步条优先说它。
- 点热点 / 列表项：问题卡（和读图问题卡同一个样子）：「次卧南墙在改造里拆掉了，墙上的衣柜没地方挂」+ 选项「挪到西墙（最近）/ 裁到剩下的墙上 / 先留着 / 删掉」。
- 拆一段墙：完全在剩下那段上的装修自动跟过去，不打扰用户（和洞口一样）；跨过拆掉那段的才问。
- 墙动了一点（拖墙角）：装修保持离墙端的距离；超出墙面的才问。
- 撤销改造（改造清单里撤一条）也一样处理。

### 5.2 受保护的墙上做嵌入

见 4.6。三处一致：检查器事实卡、平面 / 立面上的墨色锁、改造清单导出的「需要专业确认」页。措辞全部来自同一个函数（`validateDecor` 的 `protected` 文案），不会三处说法不一样。

### 5.3 三态共存

见 §3。

### 5.4 楼层

装修跟楼层走：挂在墙上的跟墙；家具、岛台写自己的 `level`。楼层切换时装修层一起切。

## 6. 改造清单导出：要不要扩展成装修清单

**要，但名字不变，还是「改造清单导出」**，一个 PDF 里分两部分：「结构改造」「装修想法」。导出面板两个开关都默认开，各自显示条数。口吻统一是「我的改造想法，尺寸和可行性以专业确认为准」，不出现「给设计师」。

装修部分的页（沿用 S2b 的版式、A4 横版、白底、黑白打印也分得清）：

| 页 | 画什么 | 写什么 |
|---|---|---|
| 装修总览 | 改造后的平面 + 材料（打印版的样色更浅）+ 家具；造型、柜子、嵌入、挖洞标序号 | 风格名；按序号一句话 |
| 墙面页（每面有造型 / 嵌入 / 柜子的墙一页） | 那面墙的立面 + 标高度、宽度 | 每个序号：做什么、尺寸、材料、业主原话；受保护墙上的写事实 |
| 柜子页（每个柜子一页，分格复杂时） | 柜子立面 + 平面局部 | 分列分格、挖洞、台面、家电位、材料 |
| 材料表 | 色块 + 名字 | 用在哪、面积粗估（「约」，只用来对量级）、业主写的品牌色号备注 |
| 家具尺寸表 | 平面符号 | 名字、宽深高 |
| 需要专业确认 | 小平面标出位置 | 承重墙 / 外墙上的嵌入、挖洞，只写事实：「方案里是外墙（读图看到）· 挖进 120 · 墙厚 240」。页脚一句：「墙里可能有水电管线，嵌入、挖槽的位置都要现场确认」 |

- 序号规则沿用 core 的 `paginate`：装修条目由新函数 `decorFocus` 给出锚点、关注框和视图（`plan` / `elevation` / `cabinet`），和结构条目一起全局编号，同一条在总览页和细节页用同一个号。
- 家具不逐件编号（太多），进尺寸表。
- 不出价格、不出品牌推荐。

## 7. 文案口径

| 场合 | 用 | 不用 |
|---|---|---|
| 受保护墙 | 「这面在方案里是外墙（读图看到）」「要专业人员到现场确认」 | 「危险」「禁止」「不建议」「违规」 |
| 挖透 | 「挖到 240 就穿了，那是开洞，属于结构改造」 | 「不允许挖穿」 |
| 尺寸参考 | 「常见尺寸，放下后可改」「常见值」 | 「标准」「规范要求」「必须」 |
| 挂不住 | 「没地方挂了」「先留着」 | 「错误」「失效」 |
| 导出 | 「导出」「改造清单导出」「我的装修想法」「都是我的想法，可行性待专业确认」 | 「给设计师」「施工说明」 |
| 剖切 | 「剖开看」「剖开看看」+「像在腰的高度把房子横着切开往下看……」 | 「水平剖切」「剖面」这类行话单独出现 |
| 弧形门窗 | 「弧形的玻璃、门一般要定制，可行性待专业确认」（只陈述，不拦） | 「不建议」「做不了」 |
| 面积 | 「约 9.3 ㎡ · 粗估」 | 「用料」「报价面积」 |

## D6 补充（本人 10-29 验收后）

- **没有装修层的方案**：悬停风格时用 core `createDecor` 临时生成一份来画（平面、3D 都跟着预览），不写进数据；按「应用」才真正创建装修层。
- **3D 里能直接选**：点墙面 = 那一侧的墙面卡（带「进立面」），点柜子 / 造型 / 挖洞 / 家具 = 对应检查器；双击墙面进立面、双击柜子进柜体编辑。
- **对准**（取代工具栏上的开发探针 P1–P3；`?probe=p1|p2|p3` 网址参数只留给 e2e 和开发）：3D 里选中柜子、造型、挖洞、家具，旁边出「对准」，相机框住它；嵌墙的柜子、壁龛、挖洞多一个「剖开看看」（打开剖切并对准）。对准期间视角按钮都不亮；点任一视角 = 退出对准、切到那个视角；「取消对准」回到最后选的视角。
- **Agent 待确认的结构提议**：装修态里只画一圈细虚线，没有淡紫斜纹和热点；「这套房的装修」卡「要你看一下」多一行「有 N 条结构提议还没确认，装修按现在的结构算」，点了切到改造态并选中那条提议。
- **弧墙上的门窗**：玻璃、门都支持弧面（先不管现实中合不合理）。2D 沿弧画符号、按「几扇」分隔；3D 是连续的弧面玻璃 / 门扇，只在扇和扇交界处有竖框（core C6 `openingSymbol` / `buildFixtures` 的 footprint）。
