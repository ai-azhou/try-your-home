# 装修阶段设计规范（E1，在 design.md 上扩展）

> 10-29 E1。`docs/design.md` 的所有规则照旧有效，本文只写装修阶段**新增或改变**的部分，每条带理由。
> 样张：`样张/*.html`（静态，零网络请求）→ `样张/png/*.png`（2 倍像素）。样张的画法代码在 `样张/tools/`，平面几何来自 core 的 `applyChanges` + `wallOutlines`（一次算好存成 `geom.json`），所以墙角、洞口和真界面一致。

## 0. 方向

**同一块白模工作台，把材料轻轻铺在白模上：结构的颜色继续只说「要你注意」，材料的颜色退一档，只说「这里铺了什么」；立面是装修阶段的第二主画布。**

- 不另起一套界面：顶栏、左工具栏、右侧卡、底部一句话、画中画、缩放条，位置和配方全部照旧。装修只换内容，不加浮层。
- 白模气质不丢：家具是白模摆件（白填充 + 细墨线 + 一层软影），不是彩色图标；材料在平面上是「样色」，不是照片。
- 立面像一张放在台面上的图纸：和平面同一套白板、投影、墨线、胶囊尺寸，剖到的东西用平面里学会的墙色。

## 2. 颜色：结构语义色和材质色怎么共存

**两个色域，两种画法，互不借用。**

| | 结构语义色（照 design.md §2.1） | 材质色（新增） |
|---|---|---|
| 是什么 | 薄荷 = 选中，柠檬 = 要你动手，淡紫 = Agent，珊瑚 = 拆，钴蓝 = 新增，墨 = 受保护，天青 = 玻璃 | 每种材料自己的颜色（`Material.color`） |
| 彩度（OKLCH C） | 0.12–0.18 | 平面里 **≤ 0.033**（压低后），立面里 ≤ 0.10，卡片色块用真实色 |
| 画法 | 「标记」：实心粉彩盘 + 白环、描边、斜纹、外发光，压在最上层 | 「面」：平涂 + 细纹理，在墙线和标记下面，从不描粗边、不发光 |
| 面积 | 小：针、线、色带、角标 | 大：整块地、整面墙 |

### 2.1 平面样色（`planTone`，样张代码 `tools/lib.mjs`）

```
OKLCH：L' = clamp(L + (1 − L) × 0.50, 0.895, 0.975)；C' = min(C × 0.6, 0.033)；色相不变
纹理线 = 同一色再暗 ΔL 0.032
```

- 为什么这样：语义粉彩的彩度都在 0.12 以上，材料压到 0.033 以下，**差 3.6 倍**——哪怕选了薄荷绿乳胶漆、粉色墙漆，平面上也只是一层淡淡的绿 / 粉，薄荷选中、珊瑚拆除照样跳出来。明度下限 0.895 保证深色地板（胡桃木）也比隔墙灰（L≈0.76）亮得多，墙线照样读得清。
- 自查：r1 用 0.32 / 0.85 / 0.045，木地板发橙、整张图像「木板游戏」；r2 提到 0.50 / 0.895 / 0.033，材料读得出、白模气质还在。
- 卡片里的色块（材料行、风格材料板、材质选择）**用真实色**：那是「样板」，要让人认出是哪种木头、哪种灰。

### 2.2 立面样色（`elevTone`）

`L' = L + (1 − L) × 0.08，C' ≤ 0.10`。立面离「真实」近一档：立面是做造型、看搭配的地方，需要看得出微水泥和木饰面的区别；立面上的语义标记很少（选中、锁、尺寸胶囊），不会被压住。

### 2.3 装修态里语义色怎么用

> D6：「Agent 待确认的结构提议」在装修态里只画一圈 1px 淡紫细虚线（3/3），不铺斜纹、不出热点（3D 里只留边线）；装修按已确认的结构算，提议在右侧卡「要你看一下」里说一句。


| 语义 | 装修态里的用法 | 变化 |
|---|---|---|
| 薄荷 · 选中 | 选中地面 / 家具 / 柜子：**只描边 + 角柄，不再整块铺薄荷**；选中墙面：贴着墙面一条 3px 薄荷色带 + 两端白圆柄 | 结构态选中房间是整块 `mint-100`，装修态那样会把材料盖掉。选中的东西还是唯一的薄荷，但不遮材料 |
| 柠檬 · 要你动手 | 没地方挂的装修（斜纹 + 虚线 + 热点）、挡门提示 | 同结构态 |
| 墨 + 锁 · 受保护 | 承重 / 外墙上的嵌入：事实卡、锁标签、导出页 | 同结构态：受保护 ≠ 危险 |
| 淡紫 · Agent | Agent 写的装修（`pending`） | 同 |
| 珊瑚 · 拆 | 装修态里**不出现**（装修不拆东西）；只留给删除按钮 | 避免「红色 = 不能做」的误读 |
| 钴蓝 | 装修态不用 | 留给结构对比 |
| 洋红 · 测量 | 拖家具时四个方向的净距胶囊（测距 spec 定的语义色，值 `#d6409f`） | 新落地的令牌 |
| 杏色 · 装修构件身份 | 只在检查器头像盘（`#efe3d2` 底 / `#6b5338` 图标）和「你加的」小标签上 | 不是提醒色，不上画布；让检查器一眼分得清「这是结构构件还是装修构件」 |

**禁止**：材料色做描边、发光、热点盘；语义色当材料（不能有「薄荷色地板」的渲染路径——用户真选了薄荷绿乳胶漆，也走 `planTone` 压下去）。

## 3. 工具栏和面板（不堆按钮）

### 3.1 左侧工具栏：跟着主画布换内容，格数不变

| 主画布 | 工具（快捷键） |
|---|---|
| 平面（装修态） | 选择 `V` · 材质 `M` · 家具 `F` · 柜子 `C` ｜ 立面 `E` |
| 立面 / 柜体编辑 | 选择 `V` · 造型 `P` · 挖 `N` · 柜子 `C` · 材质 `M` |
| 3D | 照旧（斜视、俯视、平视、白模、顶面、复位、导出图片） |

- 结构态是 6 格（含底图），装修平面 5 格，立面 5 格：左列的高度只会变短，`useLeftColumn` 的规则不用动。
- 「风格」不是画布工具，不进工具栏：入口在「这套房的装修」卡第一行（「换风格 ›」）。
- 「嵌入」和「挖洞」合成一个「挖」：框在哪就挖在哪（4.7）。少一个按钮，也少一个「我该用哪个」的判断。
- 造型、柜子、挖的子类型（背景墙板 / 护墙板 / 格栅…，高柜 / 地柜 / 吊柜）放在工具激活时顶部提示条下的类型胶囊里，和门窗工具同一个做法。

### 3.2 右侧卡（一次一张，选中什么出现什么）

| 状态 | 右侧卡 |
|---|---|
| 第一次进装修 / 点「换风格」 | 整体风格（样张 02） |
| 没选中 | 这套房的装修（样张 01）：风格一行 → 要你看一下（没地方挂、需要专业确认）→ 用到的材料 |
| 家具工具 | 家具库 |
| 选中地面 / 墙面 | 地面 / 墙面检查器（样张 05） |
| 选中家具 / 柜子 / 造型 / 挖 | 对应检查器（样张 03） |
| 柜体编辑 | 柜子检查器 + 这一格（样张 04） |

### 3.3 下一步条（装修态，按优先级取第一条）

1. 有选中 → 墨色一句怎么改，无按钮（「拖四边改尺寸，拖进墙里就是嵌入 · ⌫ 删除」）
2. 还没选风格 → 「先选一个整体风格，之后每块地、每面墙都能单独改」
3. 有没地方挂的装修 → 柠檬「拆掉次卧南墙后，1 项装修没地方挂了」+「去处理」
4. 没有家具 → 「从家具库拖几件进来，看看放不放得下」+「打开家具库」
5. 没进过立面 → 「双击一面墙，做背景墙、嵌墙柜」（无按钮）
6. 其他 → 「奶油原木 · 28 项装修」+「改造清单导出」

## 4. 2D 平面画法（装修态）

### 4.1 画的顺序

白模台面投影 → 地面材料 → 地面内沿 1px 纸白 → 地毯 → 梁（虚线）→ 柜子、造型 → 墙（照旧按类型并成多边形）→ 嵌入的缺口 → 门窗 → 家具 → 墙面色带 → 没地方挂的幽灵 → 房间名 → 尺寸 → 选中和热点。

- **地面内沿 1px 纸白**（白 90%）：像踢脚线的一道高光；深色地板也和墙分得开。开敞处（拆掉的墙位）用地面盖住，不出现「门槛」（自查 r2）。
- **墙面色带画在家具上面**：它说的是墙面，靠墙的床、柜子不能把它盖掉（自查 r1：床头墙的色带被床盖住了）。

### 4.2 材料的平面纹理（真实尺寸，跟着缩放）

| 纹理 | 画法 | 用在 |
|---|---|---|
| 木地板 `planks` | 板长 × 板宽（常见 1200 × 190）的错缝细线，0.6px，比底色暗 ΔL 0.032 | 木地板 |
| 砖 `tiles` | 按规格（600 × 600、300 × 300、900 × 1800）的格线 0.55px | 瓷砖 |
| 人字拼 `herringbone` | 45° 交错短线 | 人字拼、鱼骨拼 |
| 微水泥 / 涂料 `speckle` | 稀疏的小点 + 一两团更亮的云 | 微水泥、艺术涂料 |
| 石材 `veins` | 卡片色块里画一两道淡纹；平面里不画（太碎） | 岩板、洞石 |
| 平涂 | 无纹理 | 乳胶漆、柜门 |

- 纹理线宽按屏幕像素写（÷ 缩放 k），缩小到看不清时（板宽 < 4px）自动只剩平涂，避免摩尔纹。
- 门槛石：门洞里的白色门槛换成 `threshold` 角色的样色。

### 4.3 柜子的平面惯例（剖切高度 1.1m，常见画法）

| 柜子 | 画法 | 为什么 |
|---|---|---|
| 高柜（剖到） | 实线框（墨 `#545a63` 1.05px）+ **交叉对角线**（`#b3b8c0` 0.7px），填门板样色 | 业主看过的户型图、全屋定制图里，交叉 = 通高柜 |
| 地柜（剖切面以下，看得到） | 实线框，填**台面**样色（俯视看到的是台面）；水槽、灶台画在台面上 | 俯视就是台面 |
| 吊柜（剖切面以上） | **虚线框**（`#8e949d` 1px，5/4）+ 3% 墨填充，压在地柜上 | 和梁同一个语言：头顶上的东西画虚线 |
| 高柜里放家电 | 不画交叉，画家电外形（冰箱 = 圆角框 + 门缝线，洗衣机 = 圆筒） | 交叉的意思是「封闭储物」 |
| 柜子挖洞（洞跨过 1.1m） | 那一列画虚线（上面还有柜子）+ 细实线（下面的台面，伸出柜外的部分也画） | 样张 01 书房书桌柜：平面上看得出中间是空的 |
| 悬空柜、电视柜（在剖切面以下） | 细实线 0.85px | 看得到、没剖到 |
| 开放格（剖切处是开放格） | 和挖洞一样画**虚线**（`#8e949d` 1px，5/4）+ 3% 墨填充，不画交叉 | 交叉只表示「封闭储物」；1.1m 处是开放格 = 这一层是空的、看得到里面（本人 10-29 定） |

> **剖切 1.1 m 的统一规则（本人 10-29 定）**：一列柜子在 1.1 m 处是门、抽屉、上翻门 → 交叉；是开放格、挖洞 → 虚线（洞里有台面再加细实线）；是家电 → 家电外形。
> 样张 01 书房书桌柜最右一列（1.1 m 处是开放格）画成了交叉，和这条不一致，**以规范为准**（样张是 E1 的静态图，没有重画）。

### 4.4 嵌墙、壁龛、造型的平面表示

- **嵌入**：墙体在嵌入范围里**扣出一块**，扣掉的地方填柜子 / 龛内的样色；**原墙面画一道墨色虚线**（3/2.2）；高柜的交叉线连到墙里，看得出柜子有一截在墙里（样张 01 客厅左下角）。剩下的墙照旧是墙的颜色——剩多少一眼看得出。
- **壁龛**（不放东西）：同上，龛内填背板样色；龛不在剖切高度上时，缺口画虚线框而不是扣掉。
- **受保护墙上的嵌入**：平面上不常驻锁（平面会太花）；悬停 / 选中时缺口旁出一个白色锁热点（同改造态的受保护墙）。
- **造型**：墙面前一条实际厚度的色条（背景墙板 150 → 平面上 9px），材料样色 + 墨线 0.9px；造型上挖的洞在平面上是色条变薄的那一段，洞里的电视画成一条墨色细条（样张 01 客厅西墙）。
- **墙面换色**：墙面往房间里 1px 纸白缝 + 3px 色带，两端圆头；只画**和风格默认不同**的墙面（例外才画，默认在卡片里说）。r1 色带直接贴墙，读成了「墙变厚了」，加了纸白缝（自查 r2）。

### 4.5 家具平面块：白模摆件，不是剪贴画

| 规则 | 值 | 为什么 |
|---|---|---|
| 外轮廓 | 墨 `#545a63` 1.05px，圆角按真实尺寸（沙发 70mm、椅子 70mm） | 一种线宽说「这是一件东西」 |
| 细节线 | `#b3b8c0` 0.7px，**每件不超过 4 根**（沙发：靠背线、两条扶手线、两条坐垫分隔） | 细节多了就是剪贴画 |
| 填充 | 白模白 `#fbfaf8`；布艺、木头用风格里对应角色的平面样色（沙发 = `fabric.main`，茶几 = `wood.main`） | 白模 + 一点材料，和墙地同一套样色 |
| 投影 | 两层：近 dy 0.6 / 模糊 0.5 / 12%，远 dy 2.2 / 模糊 2.6 / 13%（按屏幕像素） | 家具「放在」地上，和整个平面的白模台面投影同族 |
| 不画 | 渐变、高光、假立体、植物、装饰品、人 | 画不好就不画（design.md §11 的老规矩） |
| 地毯 | 地毯样色 + 浅描边 + 内圈虚线（包边），永远在家具下面 | 一眼认得出是软的 |
| 符号库 | 家具库卡片里用**同一个符号**（不是图标），尺寸写在下面 | 拖进来以后长得一样 |

### 4.6 房间名

照旧（design.md §5.4）：名称 + 面积，带光晕；排布时把家具当成要避开的东西（`labels.ts` 加一类障碍）。

## 5. 立面视图：墙面立面编辑器

立面是装修 2D 的主力：造型、嵌入、挖洞、柜子在平面上只看得到一条线，在立面上一目了然。

### 5.1 取景和坐标

- **站在房间里面对墙**：左右按人的左右（数据里的换算见数据格式 §3.1），高度向上。标题第三行写「面朝西看」。
- 取景框 = 四周浮卡之外最大的矩形（`layout.freeRect`，和平面适配同一个函数）；默认适配整面墙，选中构件时适配到构件所在的那一段，墙还没完的一侧用蒙版淡出（样张 03 右边的书房）。
- 一面「墙面」可以跨几段共线的墙（拆墙后连成一片），立面按整条画；地面下方第二条尺寸链写房间分段（「客餐厅 3.42 m | 书房」）。

### 5.2 画什么

| 东西 | 画法 | 为什么 |
|---|---|---|
| 立面板 | 白板 + 两层投影（和平面台面投影同一组） | 像一张放在台面上的图纸 |
| 楼板、顶板 | 剖到：浅灰 45° 斜线（`#e6e8ec` / `#c7cbd2`） | 和检查器小立面、小剖面一致 |
| 两端剖到的墙 | **和平面同色**：外墙 `#3c424b`、承重墨色斜线、隔墙 `#adb3bc` | 在平面里学会的颜色直接能用：一看就知道两头是外墙还是隔墙 |
| 梁 | 垂直于这面墙的梁 = 剖到的一块（中灰斜线）；平行的梁 = 顶上一条虚线带 | 梁决定造型能做多高 |
| 门窗 | 同检查器小立面（白洞口、门扇虚线、窗分扇） | |
| 墙面 | 材料立面样色 | |
| 凸出来的（造型板、柜子） | 右边一道 7–9px 软影（墨紫 20% → 0），左上 1px 白 70% 高光 | 光从左上来，和玻璃高光、3D 主光同向；看得出「凸出来」 |
| 悬空的（悬浮电视柜） | 再加底边一道 12px 软影 | 看得出离地 |
| 凹进去的（壁龛、挖洞、开放格） | 里面更深一档，上沿 11–20px、左沿 9–11px 内影（墨紫 30% → 0）；层板上沿一道 2px 白 45% | 凹凸用同一束光解释，不靠图例 |
| 柜门 | 3mm 缝画成发丝线（门板色暗 ΔL 0.11）；明装拉手 = 开启边一根 2px 短杆 | |
| 家电 | 电视：深色圆角板 + 很淡的屏幕反光；放进柜格 / 洞里的家电按常见外形画虚线框 | |
| 靠墙的家具 | 淡墨虚线轮廓（床、沙发），不填色 | 帮你认墙、对齐（床头墙上看得到床的高度），不抢造型 |
| 拆掉的墙原位置 | 地面上两道很淡的竖虚线 | 告诉你「这里原来有墙」，不画剖面 |

### 5.3 尺寸

- 默认只画：整面墙总高（左侧）、房间分段（下方第二条）、选中构件的宽和高（墨色胶囊，下方第一条和左侧）。不默认画满尺寸链（design.md 的老规矩）。
- 选中造型 / 挖洞时，附近加它的关键尺寸（电视位 1,600 × 0.90）。
- 胶囊宽度按字算（中文按一个字号、数字 0.62 个字号），r2 按字符数算，中文胶囊被裁掉（自查 r2）。

### 5.4 吸附和提示

吸附目标：墙面两端、门窗洞底洞顶、梁底、顶面、其他构件的边、墙面中线。吸到了出灰色胶囊「梁底 2.55 · 造型顶对齐」，选中时变墨色。

### 5.5 选中和编辑

- 选中：2px 薄荷框 + 6% 薄荷底 + 7 个白方柄（四角 + 三边中点；底边贴地的构件不出底边柄）。柜子的列分隔线是薄荷虚线，顶上一个薄荷小药丸当抓手（样张 04）。
- 嵌入深度角标：选中嵌入构件时，构件上沿下方一个墨色胶囊「嵌进墙 120」。
- 柜体编辑：选中的格子用同一个薄荷框；格子类型在检查器里换，不在画布上弹菜单（屏幕上最多一张右侧卡的规矩）。

### 5.6 立面里的状态

| 状态 | 画法 |
|---|---|
| 没地方挂（墙拆了） | 不在立面里出现（墙都没了）；在平面上处理 |
| 超出墙面、压到洞口 | 构件柠檬虚线框 + 柠檬斜纹，旁边一句事实 |
| 受保护墙 | 标题第三行墨色锁「外墙 240」；构件检查器里事实卡 |
| Agent 提议 | 淡紫斜纹虚线框 |

## 6. 检查器（装修构件）

结构和 design.md §7.2 一样：头像盘 + 标题 + 小字（类型 · 挂在哪 · id）→ 标签行 → **事实卡（有的话，在第二行）**→ 小图 → 字段 → 材料行 → 吸底操作行。

| 部件 | 规格 |
|---|---|
| 头像盘 | 44px，杏色底 `#efe3d2` + 图标 `#6b5338`（柜子 columns-3、墙面 paint-roller、家具 sofa）；总览卡、风格卡是墨色盘 |
| 标签行 | 受保护「🔒 外墙」墨色；「嵌进墙 120 mm」灰；「你加的」杏色（Agent 加的用淡紫「Agent 提议」） |
| 事实卡 | 实心白块里：28px 墨色锁盘 + 粗体一句事实 + 灰字说明 + 「知道了」小药丸 + 「不影响继续画」；点「知道了」后收成一行 |
| 小图 | 实心白块里，标签左上、说明右上：墙面 → 小立面（真比例，两端剖到的墙按类型着色，门洞扣掉）；嵌入 → **俯视局部**（墙厚 / 挖进 / 剩 / 柜深，横竖同一比例尺）；柜子 → 平面（剖切 1.1m，和主平面同一套画法） |
| 字段 | 两列步进器（宽 mm / 高 m；柜深 mm / 嵌进墙里 mm），和结构检查器同一个 `Stepper`（等 backlog #3 的 Figma 式数字框） |
| 材料行 | 实心白块：真实色块 28px + 名字 + 「跟风格」或「单独改过」+ 右侧操作 |
| 吸底 | 「交给 Agent」+ 删除（珊瑚圆钮）；墙面检查器是「进立面做造型」+ 淡紫 Agent 圆钮 |

**为什么俯视局部而不是侧剖面**：r2 试了侧剖面，2.8m 的墙高和 240mm 的墙厚放进同一比例尺，挖进 120 只有 4px，看不出来；把纵向压扁又不是同一比例尺，会骗人（自查 r3）。嵌入要讲的是「往里多深」，俯视正好横竖都是毫米。

## 7. 卡片

- **风格卡**：两列，每格 = 材料板（152 × 92，圆角 14）+ 名字 15/600 + 三个关键词 11/500。材料板 = 地面打底占 62% 宽，墙漆、木、石叠在右边，布是一块圆角胶囊，金属是一个小圆片，每块一层很薄的暖色投影——像摊在桌上的样板。当前风格「当前」墨色小标签；正在预览的整格 2px 薄荷描边 + 「预览中」。
- **这套房的装修**：风格一行（小材料板 92 × 60 + 名字 + 「换风格 ›」）→「要你看一下」（柠檬 / 墨锁两种盘）→「用到的材料」（色块 + 名字 + 用在哪 + 面积 / 「单独改」描边标签）。卡片总高控制在 ≤ 下一步条上沿 − 16px；r1 多放了一行四格统计，卡片压到了缩放条，去掉（数字已在标题第三行）。
- **材质选择**（墙面检查器里）：分类胶囊（选中墨底白字，同工具栏选中）+ 色块网格（42px，圆角 11，选中 = 2px 薄荷外环 + 名字变深薄荷）+ 「自定义」虚线格。
- **家具库**：同材质网格的骨架，格子里画平面符号（白底），下面名字 + 尺寸。
