# 测距（类似 Figma 的 ⌥ 悬停测距）· 设计稿

> 10-29 本人提出，先设计、后续迭代实现。

## 交互

- **触发**：选中一面墙 → 按住 ⌥ Option（Windows / Linux 用 Alt）→ 鼠标悬停到另一面墙上，显示两面墙之间的距离；松开 ⌥ 就消失。选中多面墙时，以最后选中的那面为起点。
- **测的是墙面，不是中心线**：每面墙有两个长面和两个端面，按本人要求一律取较近的那组面，得到的是「净距」。中心线距离作为小字附在旁边，悬停胶囊时显示。
- **触屏没有 ⌥ 键**：检查器里加一个「测距」按钮，点了以后再点第二面墙；再点一次按钮或按 Esc 退出。
- 点距离胶囊可以复制数值。
- 第二期：没有选中时，按住 ⌥ 悬停一面墙，显示它到上下左右四个方向最近墙面的距离；测距对象扩展到门窗边和房间边，例如「窗边到墙角」。

## 计算

**横平竖直的墙**（绝大多数户型）：取两面墙足迹的外包框 A、B。墙是轴对齐的，所以外包框的边就是墙面。

| 情况 | X 方向 | Y 方向 |
|---|---|---|
| A 在 B 左边，`A.x1 < B.x0` | `dx = B.x0 − A.x1`，A 的右面到 B 的左面 | 按 Y 同样判断 |
| X 投影重叠 | 没有 X 净距，不显示 | — |
| 两个方向投影都重叠（相交或相接） | 不出数字，显示「相交」小标签 | 同左 |

- 两面平行墙，例如两面竖墙：通常只有一个方向有值，就是房间净宽。
- 一横一竖不相交：两个方向都有值。例如墙角缺口在 X 和 Y 上各差多少。

**斜墙、弧墙**：
- 两面平行的斜墙：只给一个数，即沿法向的面到面净距，标注线垂直于墙。
- 其他情况：给两墙足迹之间的最近距离，再附 Δx、Δy 分量小字；标注线连接两个最近点。弧墙用离散后的折线足迹求最近点。

## 画法

- **颜色**：用新的「测量」语义色（洋红），和选中的薄荷、拆除的珊瑚都区分开。
- **标注线**：两端带短竖线；被测的两个墙面高亮成细洋红线。
- **线的位置**：
  - 标注线放在两墙投影重叠段的中点；
  - 两墙没有重叠时，按 Figma 的做法，从对方墙面补一条虚线延长线到标注线的高度。
- **数字**：胶囊标签，单位 mm 取整，千分位，例如「3,250」。数字来自方案几何而不是屏幕像素，所以缩放时不会变。

## 实现

- core 加 `measureWalls(plan, idA, idB) → { dx?, dy?, normal?, nearest?, intersect, segments }`：segments 给出画线用的端点；函数要有单元测试。界面只负责画。
- **键盘**：macOS 浏览器里按 ⌥ 没有系统副作用。Windows 上单按 Alt 再松开，可能把焦点切到浏览器菜单，要在按键事件里拦截，上线前在 Windows 上实测。
- **难度**：中低，没有特别困难的地方，几何都能用现有的墙足迹、投影函数组合出来。
